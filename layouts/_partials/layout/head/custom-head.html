{{/* Language alternates + first-visit locale detection. Overrides the theme's empty custom-head hook. Two things happen here: 1. for every translation of the current page, plus x-default pointing at the default language. The theme emits none of these on its own; search engines need them to understand that /portfolio/, /fr/portfolio/ and /it/portfolio/ are the same page in three languages. 2. A tiny inline script that sends a first-time visitor to the version matching their browser locale. It runs before paint (this partial is in ) so there is no flash of the wrong language. Rules, in order: - Only on the first page view of a browsing session (sessionStorage flag). After that every link and the language switcher navigate normally -- the script never fights an explicit navigation. - A language picked from the switcher wins over browser detection and is remembered across sessions (localStorage). - Otherwise navigator.languages is matched against the languages this page actually exists in. Everything is wrapped in try/catch: with storage disabled or JS off the visitor simply stays on the URL they asked for. */}} {{- $abs := dict -}} {{- $rel := dict -}} {{- range .AllTranslations -}} {{- $abs = merge $abs (dict .Language.Lang .Permalink) -}} {{- $rel = merge $rel (dict .Language.Lang .RelPermalink) -}} {{- end -}} {{- if gt (len $abs) 1 -}} {{- range $lang, $url := $abs }} {{- end }} {{- with index $abs hugo.Sites.Default.Language.Lang }} {{- end }} {{- end -}} {{ partial "schema/jsonld.html" . }}
